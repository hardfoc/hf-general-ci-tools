# ADR 0001: Record architecture decisions

| | |
| --- | --- |
| Status | Accepted |
| Date | YYYY-MM-DD |

## Context

Design decisions are made in reviews and chats and then lost. A newcomer sees the code but not why it is that way.

## Decision

Each decision that shapes the code is recorded here as a short page, numbered in order, from the
[template](template.md).

## Consequences

- The reason for a design survives the people who made it.
- A changed decision is a new record that supersedes the old one, so the history stays readable.
