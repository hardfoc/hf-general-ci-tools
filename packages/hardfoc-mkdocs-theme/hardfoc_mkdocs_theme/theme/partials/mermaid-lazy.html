{#- Mermaid on demand. Material loads Mermaid (about 950 KB of script, a few hundred ms of main-thread work on a phone) on every page with a diagram, as soon as the page loads, even when the diagram is far down the page. Material skips its own loader when a global `mermaid` exists and then only calls `mermaid.initialize(config)` once and `mermaid.render(id, text)` per diagram. This stand-in answers those two calls and loads the real Mermaid only when a diagram is on the screen, or, once the reader has scrolled, pressed a key or touched the page, when it comes within a screen of it (or the page is printed); Material renders it as before, with the theme's colours. Before the reader does anything, a diagram just below the first screen waits: loading it then would run Mermaid while the page is still loading, on the main thread the page needs for its first paint. Without IntersectionObserver every diagram renders at once, as before. tests/test_plugin.py checks that Material's bundle still uses these two calls, and runs this script in Node. -#}
